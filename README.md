Student Result Management System 

Problem Statement

Manual student result calculation and record management require time and can lead to calculation errors. The project aims to develop a Python-based system that calculates student results, manages multiple student records, and displays academic performance efficiently.

Objectives

- To automate student result calculations.
- To calculate total marks, percentage, grades, and PASS/FAIL status.
- To store and manage multiple student records.
- To reduce manual work and calculation errors.
- To analyze and display student performance.

 Algorithm

1. Start the program.
2. Enter student details and marks for three subjects.
3. Calculate total marks and percentage.
4. Assign a grade based on the percentage.
5. Determine PASS or FAIL status.
6. Store student records for future access.
7. Display individual or multiple student results.
8. Repeat the process for additional students as required.
9. Stop the program.

 Concepts Used

 Features
